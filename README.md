# Pi Patchwork

円周率の小数桁を共有テクスチャ辞書として参照し、画像をパッチワーク状に再構成する不可逆の実験的画像コーデックです。

v4は可変サイズの四分木パッチを使います。予算内で誤差の大きい領域を優先して分割し、各葉を単色・RGBグラデーション・円周率辞書の模様から選びます。π模様では描画領域とは別に2×2 / 4×4 / 8×8 / 16×16の内部ソース格子を選べるため、大きな領域を低解像度の模様1枚で近似できる場合は細分化を避けられます。開始桁、色のバイアスと符号付きゲイン、回転・反転、1×/2×/4×の繰り返し密度と位相を保存します。完全一致するバイナリ列は探索せず、4×4の色特徴で候補を絞り、復元画素とパッチ境界の誤差で選びます。v1〜v3ファイルも復号できます。

## Run

```bash
npm install
npm run dev
```

`npm test` でサイズ予算、独立復号、旧形式、破損拒否を検証し、`npm run build` で本番ビルドします。`node --experimental-strip-types scripts/benchmark.ts` でサンプル画像の画質と時間を計測できます。詳細は [PLAN.md](./PLAN.md) を参照してください。
