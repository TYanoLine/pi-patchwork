# Pi Patchwork

円周率の小数桁を共有テクスチャ辞書として参照し、画像をパッチワーク状に再構成する不可逆の実験的画像コーデックです。

各パッチは円周率辞書の開始位置、色のバイアスとゲイン、回転・反転、1×/2×/4×の繰り返し密度を保存します。完全一致するバイナリ列は探索せず、復元画素の平均二乗誤差で候補を選びます。平坦な領域には単色パッチを使います。

## Run

```bash
npm install
npm run dev
```

`npm test` でサイズ予算、独立復号、破損拒否を検証し、`npm run build` で本番ビルドします。詳細は [PLAN.md](./PLAN.md) を参照してください。

## Status

MVP。圧縮効率や円周率固有の優位性は保証しません。入力はブラウザ内で処理され、外部へ送信されません。
