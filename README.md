# Pi Patchwork

円周率の小数桁を共有テクスチャ辞書として参照し、画像をパッチワーク状に再構成する不可逆の実験的画像コーデックです。

現在の形式は `.pipw v4` のみを対象にしています。旧形式との後方互換は持ちません。

## Codec

画像は可変サイズの四分木パッチに分け、各葉を単色・RGBグラデーション・円周率辞書の模様から選びます。π模様は描画領域とは別に 2×2 / 4×4 / 8×8 / 16×16 の内部ソース格子を選べるため、大きな領域でも小さな模様の拡大だけで十分なら細分化を避けられます。

共有辞書は円周率の小数部先頭 **1,000,000桁**。ビルド時に Chudnovsky 法で生成し、既知の SHA-256 と先頭桁で検証します。探索では辞書全体を数十点だけサンプリングする代わりに、各π断片を12bitの相対形状特徴で4096バケットへ分類した約512 KiBの特徴インデックスを使います。画像パッチ側も色の主成分から同じ形状特徴を作り、該当バケットの候補を中心に gain/bias・回転・反転・繰り返し・位相を再評価します。

`.pipw` の葉レコードは12 bytesのままです。内部ソース格子サイズは既存フラグ内の2bitに格納します。

## Run

```bash
npm install
npm run dev
```

`predev` / `prebuild` で `public/pi-1m.txt` と `public/pi-index-1m.bin` を再生成します。

```bash
npm test
npm run build
node --experimental-strip-types scripts/benchmark.ts
```

テストではサイズ予算、独立復号、可変ソース格子、辞書/インデックス整合性、破損拒否、旧形式拒否を検証します。詳細は [PLAN.md](./PLAN.md) を参照してください。

## Status

MVP / experiment。圧縮効率や円周率固有の優位性は保証しません。入力画像はブラウザ内で処理され、外部へ送信されません。
